# 🖥 01-A · 發放卡列表

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：📋 企劃&PM · 🖥 Web 前端 · ⚙ 後端

## 一、一句話

營運在這頁看所有發放卡、展開查哪些活動在用它，並進到建卡或編輯。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 一列一張卡 | 欄位＝發放卡名稱／reward_id／星級＋每轉押注／遊戲數／有效期／使用活動數／操作 |
| 「使用活動」N | 只算未結束的活動（進行中＋尚未開始），已結束不列不計 |
| 沒有狀態欄 | 草稿與「已啟用」統計整個移除，建卡完成即可被引用 |
| 刪除 | N＞0 時刪除鈕押灰不可點；N＝0 才可刪，且要過二次確認 |

## 三、條列規則

- 發放卡名稱只給營運看，玩家端一律顯示固定卡名「{n}★ FREE SPIN」。
- 點列展開可看這張卡被哪些未結束活動引用（欄位：campaign_id／活動名稱／期間／狀態）。
- 清單不顯示已發張數；發卡量與獎勵產出改看數據組 Tableau 報表。
- 已結束活動的引用紀錄仍留在 DB 供對帳，只是後台不顯示。
- 一張卡可被多個活動引用，這就是型錄複用。

## 四、詳細說明（DEV V1.15 原文，一字未改）

#### Ⓓ · 發放卡清單

型錄總表，每列一張發放卡。

**限制與規則**

- 欄位：發放卡名稱／reward_id／星級＋每轉押注／遊戲數／有效期／使用活動數／操作（修改・**刪除**）

- **「使用活動」N＝未結束活動數（進行中＋尚未開始）**V1.9 改——由**活動資料即時推導**，**已結束活動不計入**；此為與抽寶箱模板「使用中活動展開」（D-005）**同口徑（未結束）**

- **清單不顯示已發張數**；發卡量與獎勵產出改由**數據組 Tableau 報表**觀測（DEV V1.4 起）

- **無狀態欄位**（草稿已移除，建卡完成即可被引用）——DEV V1.6 起「狀態」欄與「已啟用」統計整個移除

- **發放卡名稱僅供營運辨識**；玩家端顯示固定卡名「{n}★ FREE SPIN」，兩者無關

**防呆與錯誤**

- 被**未結束活動引用**（進行中＋**尚未開始**）的卡：刪除鈕 **disabled 不可點**（hover 提示原因）V1.9 改——**含尚未開始的活動**，避免刪掉未開始活動要用的卡

- **N＝0**（無未結束活動引用，含「只被已結束活動引用過」）的卡：可刪除，刪除前**二次確認**（摘要卡名＋reward_id）

#### Ⓔ · 展開：引用活動

點列展開，查這張卡目前被哪些**未結束**的抽寶箱活動引用。

**限制與規則**

- **只列出未結束活動**（進行中＋尚未開始），**已結束活動不列出**V1.9 改；**展開筆數＝清單「使用活動」欄的 N**

- 欄位：campaign_id／活動名稱／期間／狀態——**狀態僅兩態：「進行中」「尚未開始」**（不再出現「已結束」）

- 本區為**純設定引用清單**（查這張卡被哪些活動引用），**不含任何發卡統計**；發卡數與獎勵產出由**數據組 Tableau 報表**觀測

- 一張卡可被多個活動引用＝型錄複用

**防呆與錯誤**

- **已結束活動的引用紀錄由 DB 留存供對帳，後台不顯示**——後台看不到不等於資料被刪，歷史引用查詢走 DB／報表
