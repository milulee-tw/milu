# 🖥 03-C · CRM 入口與活動頁浮層（iframe）

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🖥 Web 前端 · 🏗 基礎建設

## 一、一句話

背包是在遊戲內以 iframe 浮層開啟的，玩家不必離開遊戲；本頁定義入口路徑與「什麼時候必須讓開」。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 入口路徑 | 吸附浮動 icon → 展開 CRM 選單 → 點「背包」→ 選單收合 → 背包浮層開啟 |
| 按下 SPIN 當下 | 選單與背包浮層自動關閉，icon 保留在畫面上；局數與 score 照常計算 |
| 轉動中 | icon、選單、浮層一律半透明且完全不可點（點擊事件全部阻擋）；動畫結束後恢復 |
| History 項目 | 選單最下方，主標 History／副標 RECORDS；FS 卡上線前掛 SOON 佔位 |

## 三、條列規則

- 背包不再有獨立的直接入口，CRM 選單是所有 CRM 活動的共用入口。
- 浮動 icon 是遊戲畫面的常駐元件：一般模式與 FS 模式皆顯示、皆可點，並非 FS 期間限定。
- 玩家沒有任何卡時一樣能開背包，看到的是空狀態，版面與 02-B 完全一致。
- History 點下去開到「活動」分類，不 deep link 直跳卡片清單；上線後不因玩家未持卡而隱藏或置灰。
- 背包浮層內不另設歷程入口——History 是單一入口。
- 🏗 基礎建設：浮層與 icon 的開關、半透明控制由遊戲端／平台前端實作，遊戲要把「運行中」狀態通知浮層容器；背包本身的程式不因此變更。

## 四、詳細說明（DEV V1.15 原文，一字未改）

### CRM 入口與活動頁浮層（iframe）行為 （更新 2026-09-01）

> **先講清楚這是什麼**：CRM 活動頁（**含背包**）是在**遊戲內以 iframe 浮層**開啟的——玩家不必離開遊戲就能開背包看卡片。本節定義兩件事：**①玩家怎麼進到背包**（入口路徑）**②浮層與遊戲之間的互動邊界**（什麼時候要讓開、什麼時候必須鎖住不給點）。

> **入口定義（DEV V1.8 · V1.9 補明確）**：CRM 活動頁（iframe 浮層）**由吸附浮動 icon 展開的 CRM 選單進入**。玩家點選單中的「**背包**」項目 → **選單收合** → **開啟背包浮層**。**背包不再有獨立的直接入口。** CRM 選單是**所有 CRM 活動的共用入口**（抽寶箱等同列其中）；**icon 與選單本體的規則（拖曳、貼邊、顯示時機、選單項目管理）屬《抽寶箱 CRM 浮動 icon 規格》範疇**，本文件只定義「**背包**」與「**History**」兩個項目的行為。 V1.9 補明確 **吸附浮動 icon 為遊戲畫面的常駐元件**：**一般模式與 FS 模式皆顯示、皆可點擊展開 CRM 選單**，**並非 FS 期間限定**。**玩家未持任何 FS 卡時同樣能經 icon → 選單 →「背包」開啟背包**（開啟後看到的是空的／其他分頁狀態，版面同 §07）。

> **「History」選單項目 V1.12 新增**  CRM 選單（Game Center）**新增一個「History」項目**，玩家由此進入遊戲歷程查詢。 **① 位置**：**選單最下方**（現行順序之後 ⇒ Lucky Chest／Mission／Backpack／Ranking／Recommend／Favorites／**History**）。 **② 主標／副標**：主標「**History**」（key fs_hist_entry）、副標「**RECORDS**」（key fs_hist_menu_sub），格式同其他項目（Backpack／ITEMS）。 **③ 上線時機**：**與 FREE SPIN 卡同批上線**；在那之前**掛 SOON 佔位**（樣式同 Mission／Ranking 等未上線項目，不可點）。 **④ 點擊行為**：**選單收合 → 開啟遊戲歷程頁並落在「活動」分類**（不 deep link 直跳卡片清單）。完整動線與畫面規則見 DEV §09。 **⑤ 顯示條件**：上線後**不因玩家未持任何 FS 卡而隱藏或置灰**——歷史查詢需求不隨持卡數消失（同 Backpack 的處理）。 **⑥ 邊界**：**項目在選單中的排版、SOON 徽章樣式、選單本體的展開／收合與半透明規則，一律屬《抽寶箱 CRM 浮動 icon 規格》**；本文件只定義「點下去要做什麼」。 **⑦ 背包浮層內不另設歷程入口**——History 是**單一入口**，避免玩家困惑「這兩個 History 是不是不一樣」，也避免兩處各自維護。

| 規則 | 系統要做到什麼 |
|---|---|
| **spin 當下自動關閉** V1.8 精確化 | 玩家**按下 SPIN 的當下**，**展開的 CRM 選單與背包浮層自動關閉**，讓玩家專心看遊戲畫面；**吸附浮動 icon 保留在畫面上**（不隨之消失）。**FS 局數與 score 照常計算**——關閉浮層不影響任何結算數字。 |

| **責任邊界** 基礎建設備注 | 浮層／icon 的開關與半透明控制**由遊戲端／平台前端實作**——**遊戲需把「運行中」狀態通知浮層容器**。**CRM 活動頁本身不需改動邏輯**（背包程式碼不因此變更）。 |
