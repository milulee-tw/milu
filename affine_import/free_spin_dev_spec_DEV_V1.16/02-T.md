# ✅ 02-T · 本模組驗收與錯誤處理

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：✅ QA · 🖥 Web 前端 · ⚙ 後端

## 一、一句話

背包最容易出事的是「多卡歧義」與「AWC 衝突」，這兩條沒過就不能上線。

## 二、規則一覽

| 驗收情境 | 怎麼算通過 |
|---|---|
| 多卡歧義續玩同卡 | 從卡甲進場就扣卡甲，卡乙完全不動；續玩仍是同一張卡 |
| AWC 衝突押灰 | 該遊戲押灰＋提示（提示中不出現「AWC」字樣），其他遊戲照常可選 |
| AWC 雙卡衝突（第二道防線） | 跳「FREE SPIN 卡使用失敗」→ 自動走原本的免費旋轉流程；本卡次數與 score 完全不動 |
| 連點節流 | 短時間只取一次入口，玩家稍候仍正常進入，不出現「連結已失效」死路 |
| 未選遊戲不可進入 | PROCEED 押灰但看得到，下方顯示「請先選擇一款遊戲」 |
| 待啟動自動轉入 | 到點後自動出現在「可使用」分頁，毋須重新整理 |
| 提前結算 | 彈窗明示放棄次數與金額 → COMPLETED → 轉入已過期分頁，不可再進場 |
| 列表空狀態 | 載入中不得先顯示空狀態 |

## 三、條列規則

- 過期卡被點擊：不取得連結、不允許進入，整張卡置灰唯讀。
- 連結已失效：自動重新取得再導頁，不把失效狀態丟給玩家。
- 斷線或重新登入：回來續玩同一張卡、續扣同一個池，不開新卡、不觸發結算。
- 玩到一半跨過到期時間：當下那一局照常結束，結束後直接結算，不再起新局。
- 使用失敗態的畫面與文案：標題「FREE SPIN 卡使用失敗」，說明要講清楚「先完成此遊戲的免費旋轉」與「本卡次數與獎金完全不受影響」兩件事。

### 本頁錯誤處理

> 🖼 截圖：FREE SPIN 卡使用失敗錯誤彈窗

對應下表「進場時仍同時存在 AWC FREE SPIN」列。本文案尚未列入 14 語系表，正式上線前需補上一列（用途 key 可用「使用失敗內文」）並送 14 語系翻譯。

| 狀況 | 系統怎麼反應 | 玩家（或營運）看到什麼 |
|---|---|---|
| **過期卡被點擊** | **不取得連結、不允許進入遊戲**；卡片改為唯讀狀態並歸入「已過期」分頁。 | 玩家：整張卡**置灰唯讀**，按鈕不可按；狀態徽章顯示「已過期」（灰）。 |
| **進入連結已失效 / 玩家連點** | 同一張卡**短時間內只取一次連結**（節流）；若手上的連結已失效，**自動重新取得**再導頁，不把失效狀態丟給玩家。 | 玩家：正常進入遊戲。**不會看到「連結已失效」的死路**；連點只是稍等一下仍會進去。 |
| **玩到一半斷線 / 重新登入** | 回來時**續玩同一張卡**、**續扣同一個局數池**；**不開新卡、不觸發結算**。 | 玩家：背包裡還是那張卡，已用次數與累積獎金**都跟斷線前一致**。 |
| **同遊戲持多張卡** | 以**進場前綁定的那一張**為準來扣次數與累積贏分；其他卡完全不動。 | 玩家：從哪張卡進去就扣哪張；**另一張卡的次數與時間都不受影響**。 |
| **玩到一半跨過到期時間** | **當下那一局照常結束**；結束後**直接結算，不再起新局**。結算金額仍套用上限。 | 玩家：手上那局玩完，之後無法再開新局；背包卡片轉為已過期，獎金已入主錢包。 |
| **進場時仍同時存在 AWC FREE SPIN** （第二道防線） V1.6 | 跳錯誤提示「**FREE SPIN 卡使用失敗**」，隨後**自動開始 AWC FREE SPIN 流程**。**COMBO 卡不啟用、不扣次數、score 不動**；卡片有效時間照常走（不因此延長）。 | 玩家：先看到「FREE SPIN 卡使用失敗」提示 → 直接進入 AWC FREE SPIN；回背包後 COMBO 卡的剩餘次數與累積獎金與進場前完全一致。 |

### 使用失敗態

畫面與文案見 §07 本頁錯誤處理 的線框（fs_bag_06_awc_fail）；本節只列欄位與行為。

遊戲牆的押灰是第一道防線；押灰若因查詢失效等原因沒擋住，進場啟用前還有第二道驗證。第二道驗證失敗時，玩家會看到這個彈窗。

| # | 欄位 | 說明 |
|---|---|---|
| 1 | **錯誤標題與說明** | 標題「**FREE SPIN 卡使用失敗**」；說明文字要講清楚兩件事：① 請先完成此遊戲進行中的免費旋轉 ② **本卡的次數與累積獎金完全不受影響**。**玩家端文案一律不出現「AWC」字樣**（AWC 僅為內部／後台用語）。 |
| 2 | **Confirm** | 按下後**自動改走該遊戲原本的免費旋轉流程**。本卡不啟用、不扣次數、score 不動；卡片有效時間照常走，**不因此延長**。 |
| 3 | **回背包後的狀態** | 玩家回到背包時，該卡的剩餘次數與累積獎金**與進場前完全一致**——失敗不留下任何痕跡。 |
