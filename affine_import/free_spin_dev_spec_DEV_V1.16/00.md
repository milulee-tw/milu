# 📋 00 · 母計畫 Hub · FREE SPIN 卡

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、一句話

一張可在指定遊戲列表內免費轉 N 次的票券；本頁是全書索引，每個模組一個資料夾，一個功能只在一個地方說完。

| ⚙ 後端 · 🖥 前端 | 09-A 全域約定 → 09-C 術語表 → 自己負責的模組 → 該模組的 0N-T → 09-G 基礎建設 |

## 三、條列規則

- 每一頁固定三段：**一句話**（這頁在講什麼）→ **規則一覽**（一張表看完）→ **條列規則**（一條一句）。三段合計壓在 300 字內。
- 原本的長段落一字未改，收在每頁最後的**「詳細說明（原文）」折疊區**裡，要查細節才展開。
- 左側代碼樹＝AFFiNE 的頁面代碼，`sec-01-A` 就是 AFFiNE 裡的「01-A 發放卡列表」子頁。
- 每個模組固定三件套：規格子頁（0N-A、0N-B…）＋**0N-T 本模組驗收與錯誤處理**＋**0N-W Walkthrough 畫布**。
- 職能標籤共七種：📋 企劃&PM／🎲 機率組／🖥 Web 前端／⚙ 後端／✅ QA／🎨 美術／📊 數據組；🏗 基礎建設是標記，不是職能。
- 規格語義與 DEV V1.15 完全一致，本版只動結構與可讀性。
