# 🖥 02-A · 背包入口（CRM 選單）

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🖥 Web 前端 · 🎨 美術

## 一、一句話

玩家從遊戲畫面左下角的入口按鈕打開 GAME CENTER 選單，再點 BACKPACK 才真正打開背包。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 1 入口按鈕 | 遊戲畫面左下角籃子圖示，鄰近選單／設定；點擊後於按鈕正上方彈出選單 |
| 2 GAME CENTER 選單 | 背包與寶箱共用的入口選單，內含 BACKPACK 與 CHEST |

## 三、條列規則

- GAME CENTER 是所有 CRM 活動的共用入口，版面要預留能容納更多列。
- 選單本體與項目管理（拖曳、貼邊、顯示時機）屬《抽寶箱 CRM 浮動 icon 規格》，本文件只定義「背包」與「History」兩項的行為。
- CHEST 畫面與互動不在本規格範圍。
- 浮動 icon 一般模式與 FS 模式都常駐；玩家沒有任何卡時一樣能開背包（開了看到空狀態）。
