# 🖼 02-W · Walkthrough 畫布 · 背包操作流程

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：📋 企劃&PM · 🖥 Web 前端

## 一、一句話

背包端的畫布底稿：從打開背包到進場的主路徑，加上封頂提前結算這條分流。

## 二、規則一覽

| 路徑 | 步驟 | 對應規格頁 |
|---|---|---|
| 主路徑 | 遊戲畫面 icon → GAME CENTER → BACKPACK → 展開卡片 → 選攜帶遊戲 → PROCEED → 進場 | 02-A → 02-B |
| 封頂分流 | 卡片出現 MAX 徽章 → SETTLE NOW → 二次確認 → COMPLETED → 卡片轉入已過期 | 02-D |
| 不能用的分流 | 空狀態 ／ 待啟動（PROCEED 永遠押灰）／ 已過期（整卡置灰） | 02-E |

## 三、條列規則

- 畫布尚未建置：本頁先列出三條路徑的節點，畫布建好後把每張卡片綁到對應規格頁的標題。
- 綁定鐵則：一張卡片只綁一個 h2 標題，標注編號＝h4 編號，一個流程一份文件。
- 畫面導覽流程圖（實線＝正常遊玩、虛線＝取消、紅線＝到期）已在 05-A，畫布可直接沿用該張圖的分流邏輯。
