# 🎨 05-D · 動態文字與位數限制表

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🎨 美術 · 🖥 Web 前端

## 一、一句話

會被數字撐爆的欄位都在這張表：金額最長 12 字元、次數 2 位數、倒數 8 字元。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 金額 | 12 字元（含幣值符號與千分位） |
| 次數 | 2 位數 |
| 倒數 | 8 字元（0D:00:00） |
| 卡名 | 固定全語系統一，不因語系變長 |

## 三、條列規則

- IDR／VND 等大面額幣別位數很長，版面要先照最長的情況排。
- 原文表格留在下方明處，美術與前端直接照表切版。

## 四、原文表格（不折疊）

### D · 動態文字與位數限制表 （更新 2026-08-25）

> **這張表給誰用**：**美術**依此**預留版位寬度**，**前端**依此**實作格式與縮字**。表內為**前端渲染文字**，**美術一律不出文字圖**（唯二例外：FREE SPINS 橫幅與 FREE 字樣，見 C 表 19／22／23）。

| 項目 | 格式 | 位數／長度上限 | 範例 |
|---|---|---|---|
| **金額** 累積獎金／最大獎金／結算 Bonus／bet | 幣別符號 ＋ 千分位 | 含符號最長 **12 字元**，超過**由前端自動縮字** | ₱999,999.99 |
| 次數 | n/N | 各 **2 位數**（上限 99） | 5/10 |
| 星級 | {n}★ | n＝**1–5** | 3★ |
| 倒數（>24h） | d天 hh:mm | d 最大 **2 位數** | 2天 05:30 |
| 倒數（<24h · **紅色**） | hh:mm:ss | **固定 8 字元** | 03:45:12 |
| 待啟動倒數 | {t} 後開始（t 同倒數格式） | 同上 | 2天 05:30 後開始 |
| FREE 計數器 n | 整數 | **2 位數** | 8 |
| 卡名 | {n}★ FREE SPIN | **固定、全語系統一** | 3★ FREE SPIN |
| 選單項目名 | 短名 | 中文 **≤6 字**／英文 **≤12 字元** | 背包 / Backpack |

> **以上為企劃建議值初稿**——**美術與前端如有排版衝突，回報企劃調整後升版**。幣別符號**依玩家錢包幣別**（64 幣值清單見 §06）。
