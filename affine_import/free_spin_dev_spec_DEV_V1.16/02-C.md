# 🖥 02-C · 選卡與進入遊戲（橫式版面）

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🖥 Web 前端 · 🎨 美術

## 一、一句話

橫式下同一張卡的按鈕會在 VIEW DETAILS 與 CLOSE 之間切換，Select Game 改開在列表旁的獨立面板。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 卡片按鈕 | 未選取＝VIEW DETAILS；選取後同一位置變成 CLOSE，用來取消選取、收回面板 |
| 選取標示 | 卡片外框同步標示 |
| Select Game 面板 | 選取任一張卡後才在列表旁開啟；面板內只有 PROCEED |
| CLOSE 的位置 | 留在卡片上，不在面板中重複出現 |

## 三、條列規則

- 橫式卡片尺寸會略微縮小，不是直式卡片原尺寸直接搬過去。
- 直式的 Select Game 則內嵌在同一張卡片裡，卡片最下方為 CLOSE／PROCEED。
- 遊戲格三種樣式互斥（Selected／Default／Locked），細節見 05-B。

## 四、詳細說明（DEV V1.15 原文，一字未改）

### FREE SPIN卡 — 橫式選取前後對照

橫式下，同一張FREE SPIN卡在未選取與已選取時，卡片下方的按鈕會換成不同文字：未選取為 VIEW DETAILS，選取後同一位置變成 CLOSE，並在列表旁開啟獨立的 Select Game 面板；面板內僅有 PROCEED，CLOSE 留在卡片上，不會在面板中重複出現。另外，FREE SPIN卡置入橫式版面時，尺寸會略微縮小，並非直式卡片原尺寸的直接搬移。

- 選取狀態**同時以卡片外框標示**
