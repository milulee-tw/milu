# 🎨 05-B · 元件美術規格（星級／徽章／遊戲格）

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🎨 美術 · 🖥 Web 前端

## 一、一句話

三組要逐狀態切圖的元件：1★–5★ 獎勵圖示、五態狀態徽章、Select Game 遊戲格三態。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 星級 1★–5★ | 銅／銀／金／白金／彩鑽，材質為主要區分，卡框與底紋同步變化，星數圖示同時顯示 |
| 狀態徽章五態 | 待啟動(藍紫)／使用中(金)／全新(綠)／即將到期(紅)／已過期(灰) |
| 遊戲格三態 | Selected（粗邊框＋打勾徽章＋文字加粗）／Default／Locked（鎖頭＋文字變暗、不可點） |

## 三、條列規則

- 不只靠色相區分：明度與底紋也要同步變化，色弱玩家才辨識得出來。
- 選取狀態同時用邊框、打勾徽章與文字粗細三個線索標示，不單靠顏色。
- 已過期卡整張透明度降低約 50% 呈現置灰，且無 VIEW DETAILS、不可展開。
- 待啟動與即將到期一樣可以展開瀏覽 Select Game，只是分頁歸屬不同。
- Locked 點擊時顯示「請先完成此遊戲的免費旋轉」，玩家端一律不出現「AWC」字樣。
- 卡片生命週期四條結束路徑：①用完局數 ②a 到期未用 ②b 到期已用一部分 ③封頂後 SETTLE NOW；達上限本身不會自動結束卡片。

## 四、詳細說明（DEV V1.15 原文，一字未改）

### 獎勵圖示 — 星級分級

五個星級以**材質**做主要區分，卡框與底紋隨材質同步變化；星數圖示同時顯示。

> 🖼 截圖：1★ 銅、2★ 銀、3★ 金、4★ 白金、5★ 彩鑽

| 星級 | 材質 | 卡框與底紋 |
|---|---|---|
| 1★ | 銅 | 銅色邊框＋霧面底紋；星數圖示顯示 1 顆 |
| 2★ | 銀 | 銀色拉絲邊框＋冷色底紋；星數圖示顯示 2 顆 |
| 3★ | 金 | 燙金邊框＋暖色底紋（系統主視覺基準）；星數圖示顯示 3 顆 |
| 4★ | 白金 | 冷白金屬邊框＋鏡面底紋；星數圖示顯示 4 顆 |
| 5★ | 彩鑽 | 彩色折射邊框＋稀有底紋；星數圖示顯示 5 顆 |

### 標籤 — 狀態徽章（五態）

五個狀態各自對應一組顏色與樣式規則，不只靠色相區分 — 明度與底紋也同步變化，色弱玩家仍能辨識。

> 🖼 截圖：待啟動、使用中、全新、即將到期、已過期

> 🖼 截圖：Expiring soon / pending / expired card states

「待啟動」與「即將到期」等其他狀態一樣可以展開瀏覽 Select Game（僅顯示於背包「PENDING」篩選，尚未到開始時間不影響瀏覽）；「已過期」則整卡不可互動、無法展開（僅顯示於背包「EXPIRED」篩選）。

| 狀態 | 顏色 | 樣式規則 |
|---|---|---|
| 待啟動 | 藍紫 | 僅顯示於背包「PENDING」篩選；玩家可展開查看此卡可用的遊戲，但尚無法實際使用兌換 |
| 使用中 | 金 | 玩家使用過此卡後，即轉為此狀態 |
| 全新 | 綠 | 尚未使用（已用 0 次）且已可使用 |
| 即將到期 | 紅 | 剩餘時間少於 24 小時；顯示倒數計時 |
| 已過期 | 灰 | 無 VIEW DETAILS 按鈕、不可展開，整張卡片透明度降低約 50％呈現置灰效果；僅顯示於背包「EXPIRED」篩選 |

> 🖼 截圖：FREE SPIN卡生命週期：Pending 經 Available 到已結束，共四條結束路徑

### Select Game 遊戲格 — 方塊狀態

三種樣式互斥 — 一個方塊在同一時間只會是其中一種；選取狀態同時以邊框、打勾徽章與文字粗細三個線索標示，不單靠顏色。

> 🖼 截圖：Selected, Default, Locked game tiles

| 狀態 | 樣式規則 |
|---|---|
| Selected | 深色粗邊框＋右上角打勾徽章，遊戲名稱文字加粗；同一時間僅能有一格為此狀態 |
| Default | 灰底方塊、一般樣式，可點擊選取 |
| Locked | 深灰底方塊，縮圖上覆蓋鎖頭圖示，遊戲名稱文字變暗，不可點擊；點擊時顯示提示「**請先完成此遊戲的免費旋轉**」（觸發條件與文案見 [§07 Ⓔ]()；玩家端一律不出現「AWC」字樣） |
