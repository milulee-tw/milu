> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、一句話

卡片走「燙金票券／珍藏卡」：深色底＋金色主調、票券撕角與鋼印壓紋，延續抽寶箱的視覺系統。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 主體意象 | 實體票券質感——燙金邊框、票券撕角、鋼印壓紋 |
| 色調 | 深色底＋金色主調，與現有背包原型的深金風格一致 |
| 為什麼選它 | ① 與抽寶箱視覺連貫，玩家一眼看得出卡從寶箱來 ② 可複用抽寶箱既有材質庫，大幅降低新製作量 |
| 不做什麼 | 不另起一套與抽寶箱無關的視覺語言；不用純扁平無質感卡面 |

### 主題調性 · 燙金票券／珍藏卡

| 項目 | 定案內容 |
|---|---|
| 主體意象 | 卡片呈**實體票券質感**——燙金邊框、票券撕角、鋼印壓紋，傳達「**從寶箱抽出的珍藏票**」的價值感 |
| 色調 | **深色底 ＋ 金色主調**，延續抽寶箱金色寶箱的視覺系統，與現有背包原型的深金風格一致 |
| 為什麼選它 | ① **與發卡來源（抽寶箱）視覺連貫**——玩家一眼看得出這張卡是從寶箱來的；② **可複用抽寶箱既有材質庫**，大幅降低新製作量 |
| 不做什麼 | 不另起一套與抽寶箱無關的視覺語言；不用純扁平無質感卡面（會失去「珍藏票」的價值感） |

### 畫面導覽總覽

從打開背包到進入遊戲、開始使用免費旋轉的完整路徑；也包含達到獎金上限後的提早結算分流。
