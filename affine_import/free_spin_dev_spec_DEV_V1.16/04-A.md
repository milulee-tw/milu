# 📋 04-A · 職責切分與入口規則

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：📋 企劃&PM · 🖥 Web 前端 · 🏗 基礎建設 · 📊 數據組

## 一、一句話

這一章橫跨兩個系統：CRM 端只加一個 History 入口，其餘四項都是遊戲端要改的，別開成同一張單。

## 二、規則一覽

| 項次 | 歸屬 | 工作內容 | 職能單位 |
|---|---|---|---|
| H1 | CRM 端 | 選單最下方新增 History 項目，點擊開到「活動」分類 | CRM 前端 |
| H2 | 遊戲端 | 活動分類頁（L2）新增「FREE SPIN 卡」入口卡 | 遊戲前端 |
| H3 | 遊戲端 | 新增卡片清單層（L3），以 reference_id 分組、含日期篩選器 | 遊戲前端 |
| H4 | 遊戲端 | 局歷程列表（L4）沿用既有注單列表元件，欄位口徑調整 | 遊戲前端 |
| H5 | 遊戲端 | 盤面頁（L5）只置換頂部 Balance 區塊為 reference_id | 遊戲前端 |
| H6 | 🏗 基礎建設 | FS 卡歷程獨立 DB ＋ 歷程 API 統一輸出 | 後端基建 |
| H7 | 數據 | 確認 FS 局的 bet／win 不計入單一遊戲收入統計 | 數據組 |

## 三、條列規則

- 這一章存在的唯一理由：FS 卡的每一局不進一般注單，沒有專屬入口的話玩家與客服都查無此局。
- 唯一入口＝CRM 選單 › History；背包浮層內不另設入口。
- 不 deep link 的理由：與抽寶箱歷程入口採同一慣例，遊戲端也不必為 CRM 開帶參數的專用入口。
- 玩家沒有任何卡時 History 仍顯示可點（不隱藏、不置灰），點進去看到空狀態。
- 遊戲歷程 › 活動是遊戲端既有動線，行為與 History 入口一致。

## 四、詳細說明（DEV V1.15 原文，一字未改）

> 本頁目的 讓玩家自己查得到「**我這張 FREE SPIN 卡玩了哪些局、贏了多少分、最後實際拿到多少錢**」。 FS 卡的每一局**不進一般注單**（規則見 DEV §02），若沒有專屬查詢入口，玩家與客服都查無此局——這是本章存在的唯一理由。 **結算的那一筆**（下注 0／派彩 final）仍在一般注單，本章負責**把兩邊接起來**，讓玩家看得到「分數 → 實付金額」的因果。

> **先讀這段 · 本章橫跨兩個系統，開單前務必分清楚**  本章描述的動線裡，**CRM 端只做一件事**：在背包浮層加一個「History」入口，把玩家送進遊戲端既有的「遊戲歷程」頁。 **其餘四項都是遊戲端要改的**：活動分類頁新增 FREE SPIN 卡入口、卡片清單層、局歷程列表、盤面頁欄位置換。  兩邊的工作項與職能已在下方〈職責切分〉表中拆開，**不要開成同一張單**。

### 職責切分（開單依據）

| 項次 | 歸屬 | 工作內容 | 職能單位 |
|---|---|---|---|
| H1 | **CRM 端** | CRM 選單（Game Center）**最下方**新增「History」項目（主標 History／副標 RECORDS；FS 卡上線前掛 SOON 佔位），點擊後收合選單並呼叫遊戲端遊戲歷程頁、直接落在「活動」分類（**不 deep link 直跳卡片清單**）。**背包浮層內不另設入口**。項目排版與 SOON 徽章樣式屬《抽寶箱 CRM 浮動 icon 規格》 | CRM 前端 |
| H2 | 遊戲端 | 活動分類頁（L2）新增「FREE SPIN 卡」入口卡，與既有「抽寶箱」並列 | 遊戲前端 |
| H3 | 遊戲端 | 新增卡片清單層（L3）：以 reference_id 為分組主鍵，可展開；含日期篩選器 | 遊戲前端 |
| H4 | 遊戲端 | 局歷程列表（L4）沿用既有注單列表元件，欄位口徑依本章調整 | 遊戲前端 |
| H5 | 遊戲端 | 盤面頁（L5）沿用既有元件，僅置換頂部 Balance 區塊為 reference_id、調整 Bet／Win 顯示口徑 | 遊戲前端 |
| H6 | **基礎建設** | FS 卡歷程獨立 DB 架構 ＋ 歷程 API 統一輸出（同一份資料同時餵一般注單與 FS 歷程，避免兩處各自維護） | 後端基建 |
| H7 | 數據 | 確認 FS 局的 bet／win **不計入單一遊戲收入**的統計口徑（避免遊戲營收被卡片面額灌水） | 數據組 |

### 入口規則

| 入口 | 行為 |
|---|---|
| **CRM 選單 › History** V1.12 新增 | **唯一入口**。遊戲畫面吸附浮動 icon → 展開 CRM 選單（Game Center）→ 點**最下方的「History」項目** → 選單收合 → **開啟遊戲歷程頁並落在 L2 活動分類**，**不直跳 L3**。 **為什麼掛在選單而不是背包**：歷程是**跨活動**的（抽寶箱獎勵與 FS 卡都查得到），與背包同屬「玩家自己的東西」，掛在共用選單才對得上它的涵蓋範圍；**背包浮層內不另設入口**，維持單一入口。 **不 deep link 的理由**：與抽寶箱 DEV V1.19 的歷程入口**採同一慣例**（開到活動分類、由玩家自己選要看哪個活動），兩個 CRM 玩法的入口行為一致，遊戲端也不必為 CRM 開帶參數的專用入口。 **玩家未持任何 FS 卡時 History 仍顯示可點**（不隱藏、不置灰），點進去看到的是空狀態。 **選單項目本身的規格**（位置、主副標、SOON 佔位、樣式邊界）見 DEV §08。 |
| **遊戲歷程 › 活動** | 遊戲端既有動線。玩家自 L1 選「活動」分類 → L2，行為與上者一致。 |
