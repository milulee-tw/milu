# 🖥 01-C · 道具基礎值與公版數值

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：📋 企劃&PM · ⚙ 後端

## 一、一句話

每個幣值一組 1★–5★，營運只填「每轉押注」一個數字，其餘全部自動算。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 每轉押注 bet | 營運在道具基礎值直接填的單一數值（V1.3 起廢除 coin_size × multiplier 推算） |
| face_value | ＝ bet × 次數（票面價值，成本估算與對帳用） |
| max_conversion | ＝ face_value × 封頂倍數（示意用 ×10，可逐段調） |
| 次數 | 預設全段 10，可逐段調 |
| 支援幣值 | 64 項下拉選單（含搜尋），依 Combo 平台貨幣設定 |

## 三、條列規則

- 各幣值已填的數值各自保留，下拉切換幣值不清空、不互相覆蓋。
- 同一個 reward_id（R_FS_nSTAR）跨幣別共用，但各幣別數值獨立存放。
- 每轉押注須對齊該幣別遊戲端實際可用的最小押注段，避免送出遊戲端不接受的組合。
- IDR／VND 等大面額幣別，輸入與顯示都要千分位，過長時以縮寫輔助（如 1.5M）。
- bet 為 0、負數或空值時擋下儲存。
- 改基礎值只影響之後發出的卡，已發卡走快照不受影響。
