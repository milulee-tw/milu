# 🖥 03-D · 結算彈窗

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：🖥 Web 前端 · ⚙ 後端 · 🎨 美術

## 一、一句話

卡片結束時跳一次結算彈窗，顯示這張卡最後給了多少錢，按 CONFIRM 回一般模式。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| Ⓐ 標題 | FREE SPINS（美術圖）＋ COMPLETED |
| Ⓑ CampaignID | 客訴查詢用，可長按複製 |
| Ⓒ 遊戲縮圖 | 沿用遊戲既有圖庫；抓不到時以純色底＋遊戲名文字替代，不可開天窗 |
| Ⓓ Bonus Amount | ＝min(score, max_conversion)；達上限時另顯示 Max Cap Reached 徽章 |
| Ⓔ 最低可提領金額 | 已確認移除——本卡無門檻、無流水，原型實拍已無此欄位 |
| Ⓕ CONFIRM | 本彈窗唯一出口：不做 ✕、也不做「點擊任意處關閉」 |

## 三、條列規則

- 出現時機＝最後一局結束，或到期時玩家仍在遊戲中；整張卡只結算一次，彈窗也只出現一次。
- 結算尚未成功時不得先跳彈窗，避免顯示金額與實際入帳不符。
- 金額為 0 也要顯示彈窗（顯示 0），不可靜默結束讓玩家以為卡片消失。
- 金額必須與背包已過期卡的 Current Winnings 完全一致。
- 不寫「Maximum Payout Amount」——此金額通常低於上限，寫成「最高」會造成誤解。
- 按下後：FS 標記消失、押注解鎖回玩家自選、錢包已含本次 Bonus，停在同一款遊戲的一般模式，不自動跳回背包。
- CONFIRM 與 02-D 提前結算完成畫面共用同一顆按鈕文案，兩個結算出口玩家看到的字一致。

### 區域詳細說明 · 畫面三

#### Ⓐ · 標題 Free Spins Completed

告訴玩家這張卡結束了。

**限制與規則**

- 出現時機＝**最後一局結束**，或**到期時玩家仍在遊戲中**

- 整張卡**只結算一次**，本彈窗也只出現一次

- **標題視覺上排為兩段**：上段「**FREE SPINS**」（美術圖，全語系統一英文）＋下段「**COMPLETED**」——[DEV §07 文案表]() fs_exit_title 仍是完整語意的一條 key，**前端依版面決定是否拆行，不得改變語意**V1.14 補

**防呆與錯誤**

- 結算尚未成功時**不得先跳彈窗**（避免顯示金額與實際入帳不符）

#### Ⓑ · CampaignID（客訴查詢用）

這張卡是哪一檔活動發的。

**限制與規則**

- 顯示 campaign_id，可長按複製（若遊戲端支援）

- **【待確認】**建議同時顯示卡序號 reference_id——客服查單以卡序號最快（見 §03 待確認⑦）

**防呆與錯誤**

- ID 為專名**不翻譯**、不換行截斷

#### Ⓒ · 遊戲縮圖

這次是在哪一款遊戲裡用掉的。

**限制與規則**

- 顯示**本次攜帶的遊戲**縮圖（沿用遊戲既有圖庫）

**防呆與錯誤**

- 圖抓不到時以純色底＋遊戲名文字替代，**不可讓彈窗開天窗**

#### Ⓓ · Bonus Amount · 本次結算金額

這張卡最後給了多少錢。

**限制與規則**

- 金額＝min(score, max_conversion)，幣別依玩家錢包

- 此金額為**主錢包真金、無流水**，關窗後即可正常提領或續玩

- 金額為 **0 也要顯示彈窗**（顯示 0），不可略過

**防呆與錯誤**

- 金額必須與背包**已過期卡的 Current Winnings**（該卡最終結算金額）完全一致V1.15 改

#### Ⓔ · ⛔ 最低可提領金額（已確認移除）

早期美術 mockup 曾出現的門檻文字；原型實拍已無此欄位，實作不做。

**限制與規則**

- **本卡無最低獲得金額門檻、無提領門檻、無流水**——此欄位不存在

- Ⓓ 下方直接接 Ⓕ 按鈕，中間留白即可

**防呆與錯誤**

- 若後續要加門檻，屬**規則變更**需重新拍板並同步風控章，不可由美術稿逕行帶入

#### Ⓕ · CONFIRM

關窗並回到一般模式（**本彈窗唯一出口**）。V1.15 改

**限制與規則**

- 按下後：FS 標記消失、押注解鎖回玩家自選、**錢包顯示已含本次 Bonus**

- 停在**同一款遊戲**的一般模式，不自動跳回背包

- **按鈕文案為「CONFIRM」**——與 [§07 提前結算完成畫面]() 共用同一顆按鈕文案，玩家在兩個結算出口看到的字一致V1.15 改

- **本彈窗唯一出口**：不做右上角 ✕、也不做「點擊任意處關閉」——這一步已入帳真金，需要玩家明確按下V1.15 改

**防呆與錯誤**

- 回一般模式後**下一局起算真錢**，押注額須明確恢復為玩家自選值

- 不論以何種方式關窗，**獎金都已入帳**；關窗不影響發放

### 結算彈窗

玩家用完該FREE SPIN卡的所有免費旋轉次數後，出現這個彈窗；按下 **CONFIRM** 關閉並返回遊戲一般模式（本彈窗**唯一出口**，不做「點擊任意處關閉」）。直式與橫式共用同一張畫面。版面沿用 §08 畫面三。

> 🖼 截圖：Exit popup showing settlement result

| # | 欄位 | 說明 |
|---|---|---|
| 1 | FREE SPINS COMPLETED | 標題文字，告知玩家此FREE SPIN卡的免費旋轉已全部使用完畢 |
| 2 | ID | 此次使用的FREE SPIN卡兌換識別碼，供玩家或客服對照查詢 |
| 3 | 遊戲圖示與名稱 | 玩家選擇並完成免費旋轉的遊戲 |
| 4 | **Bonus Amount** | 本次免費旋轉**實際派發**的獎金＝min(score, 上限)；達到 Max 上限時額外顯示「Max Cap Reached」標籤，未達上限則不顯示。**不使用「Maximum Payout Amount」**——此金額通常低於上限，寫成「最高」會造成誤解（該字樣只用於進場提示彈窗） |
| 5 | **CONFIRM** | 綠色實心按鈕，本畫面唯一出口：按下後 FS 標示消失、押注解鎖回玩家自選、錢包顯示已含本次獎金，停在**同一款遊戲的一般模式**，不自動跳回背包 |
