# 🖥 01-B · 建卡與編輯表單

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框
> 職能：📋 企劃&PM · 🖥 Web 前端 · ⚙ 後端

## 一、一句話

營運在這頁建一張卡：選星級、勾遊戲、填次數與封頂、設有效期，按「建立發放卡」並二次確認即生效。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| Ⓐ 名稱＋星級 | 名稱只給營運辨識；星級選定後帶出各幣值每轉押注（唯讀） |
| Ⓑ 可用遊戲列表 | 搜尋加入，最多 8 款，即時顯示「已選 n / 8」 |
| Ⓒ 發放參數 | 填次數與封頂倍數；face_value 與 max_conversion 自動算出、唯讀 |
| Ⓓ 有效期＋入帳目標 | 預設「發卡 +N 天」自然日 GMT+8；入帳目標固定主錢包真金、唯讀 |
| Ⓔ 動作列 | 只有「取消」與「建立發放卡」，送出前二次確認 |

## 三、條列規則

- reward_id（RWD_FS_xxxx）在二次確認通過的那一刻才產生——新增表單上不得出現任何 ID 版位（空欄、灰字 placeholder、「建立後產生」字樣都不行）。
- 編輯既有卡時才顯示 reward_id：表單頂部一行輔助色小字，唯讀＋一鍵複製。
- 這樣改的理由：中途放棄新增不會留下永遠用不到的廢號，型錄不斷號。
- 已選滿 8 款時其餘選項押灰，不會出現超選後才擋下的狀況。
- 已發出的卡走快照，之後怎麼改都不受影響（見 09-A）。

## 四、詳細說明（DEV V1.15 原文，一字未改）

> 本頁目的 營運在這一頁**建一張發放卡**：選星級道具（押注價值固定、全幣值預設），只需設定**遊戲／次數／封頂／有效期**。**草稿已移除——填完按「建立發放卡」（含二次確認）即生效**；發出去的卡走快照，之後怎麼改都不受影響。

### 區域詳細說明

#### Ⓐ · 名稱＋星級選擇

填發放卡名稱、點選星級；獎勵道具 ID 於建卡確認後才產生。V1.14 改

**限制與規則**

- **發放卡名稱僅供營運內部辨識**，玩家不會看到——玩家端顯示固定卡名「{n}★ FREE SPIN」（DEV §07）

- reward_id（RWD_FS_xxxx）**於「建立發放卡」二次確認通過的那一刻才產生**——新增表單開啟時**不預先配號、也不渲染任何 ID 版位**（不是顯示空值或「建立後產生」字樣，是整個欄位不存在）V1.14 改

- **編輯既有卡時才顯示** reward_id：置於**表單頂部一行輔助色小字**（唯讀＋一鍵複製），字級明顯低於發放卡名稱、**不與名稱同級並列**——與抽寶箱後台「模板 ID 顯示於編輯器頂部（唯讀＋一鍵複製）」同一套做法，兩份規格保持一致V1.14 改

- **為什麼這樣改**：原本只要點開新增表單就配號，營運中途放棄就留下一個永遠用不到的廢號；改為建卡完成才產生後，型錄不會出現斷號，客服依號查單也不會查到不存在的卡

- 星級押注價值＝道具基礎值的 bet，選中後唯讀帶出各幣值每轉押注

**防呆與錯誤**

- 名稱必填

- reward_id 由系統產生，**任何模式皆不可手改**

- **新增模式下不得出現任何形式的 ID 版位**——包含空欄位、灰字 placeholder、「建立後產生」提示文字，出現任一種即不符本規格V1.14 改

#### Ⓑ · 可用遊戲列表

搜尋＋點選加入這張卡可玩的遊戲。

**限制與規則**

- 已選遊戲顯示為可移除 chip

- game_ids **最多選 8 款**，即時顯示「**已選 n / 8 款**」（DEV V1.6 起廢除逗號串 200 字元限制）

- **發卡後鎖定不可改**（快照）

**防呆與錯誤**

- **已選滿 8 款時，其餘遊戲選項押灰不可再加**；不會出現超選後才擋下的狀況

#### Ⓒ · 發放參數（次數／結算封頂）

填免費旋轉次數與結算封頂倍數。

**限制與規則**

- 次數＝**整卡共用池**（跨遊戲一起扣）

- face_value＝bet × 次數，自動計算唯讀

- 各幣值 max_conversion＝bet × 次數 × 倍數，**自動計算唯讀**

**防呆與錯誤**

- 次數／倍數為 0 或負數擋下

- 結算上限低於票面價值跳警示

#### Ⓓ · 有效期＋入帳目標

設定卡片有效期；入帳目標唯讀顯示。

**限制與規則**

- 預設「發卡 +N 天（相對）」；起算基準預設「發卡日為第 1 天」

- **自然日制 GMT+8、第 N 天 23:59:59 到期**；絕對日期為次要選項

- 入帳目標固定「主錢包真金 · 無流水」

**防呆與錯誤**

- N 必填

- 入帳目標不可編輯

#### Ⓔ · 動作列

完成建卡：取消或啟用。

**限制與規則**

- 只有「**取消**」與「**建立發放卡**」兩鈕（編輯模式＝「儲存」）——**儲存草稿已移除**，建卡完成即可被引用

- 建卡完成後即可被抽寶箱獎池下拉引用

**防呆與錯誤**

- 送出前**二次確認**（摘要星級／次數／有效期／上限／遊戲數）

- 必填缺漏時不可送出
