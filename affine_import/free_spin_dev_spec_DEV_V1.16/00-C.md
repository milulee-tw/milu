# 📋 00-C · 頁面地圖與入口路徑

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、一句話

整條鏈路只落在 5 個功能頁面上，外加一個入口：遊戲內 CRM 選單。

## 三、條列規則

- 一個功能只在一個地方說完：該頁的畫面、規則、防呆、驗收與錯誤處理全部集中在同一個模組。
- 背包沒有獨立入口：遊戲內吸附浮動 icon → 展開 CRM 選單 → 點「背包」。
- CRM 選單是所有 CRM 活動的共用入口（抽寶箱等同列），icon 與選單本體規則屬《抽寶箱 CRM 浮動 icon 規格》。
- 頁面之間怎麼接：建卡（01-B）→ 型錄（01-A）→ 抽寶箱活動引用 → 玩家抽中發卡 → CRM 選單 → 背包（02）→ 遊戲內使用與結算（03）。

## 四、詳細說明（DEV V1.15 原文，一字未改）

### 玩家端進入背包的路徑（直式） （更新 2026-08-25）

入口. **遊戲內吸附浮動 icon** — 遊戲畫面上的 CRM 入口 icon（可拖曳、自動貼邊）；**本體規則見抽寶箱 CRM 浮動 icon 規格**

展開. **CRM 選單（所有 CRM 活動共用入口）** — 點 icon 展開；**抽寶箱、背包等 CRM 活動同列其中**

背包. **點「背包」→ 選單收合 → 開啟背包浮層** — **背包不再有獨立的直接入口**；開啟後的背包內容與規則見 DEV §07，入口與浮層行為見 DEV §08

### 頁面地圖（本文件的功能頁面章）

整條鏈路落在 **5 個功能頁面**上（另加一個**入口**：遊戲內 CRM 選單）；每個頁面一章，該頁的畫面、規則、防呆、驗收與錯誤處理**全部集中在該章**，查一個功能不必跨章拼湊。

| 頁面 | 誰在用 | 這一頁做什麼 | 對應章節 |
|---|---|---|---|
| 後台 · 發放管理列表 | 營運 | 發放卡型錄總覽、道具基礎值維護、引用活動追蹤、停用把關 | DEV §05 |
| 後台 · 新增／編輯發放卡 | 營運 | 建卡：選星級、勾遊戲、填次數與封頂、設有效期，按「啟用」（含二次確認）即生效 | DEV §06 |
| 玩家端 · **遊戲內 CRM 選單** V1.8 新增 | 玩家 | **背包與歷程的唯一入口**：遊戲畫面上的吸附浮動 icon → 點擊展開 CRM 選單 → 點「背包」或**最下方的「History」**V1.12 新增。選單為所有 CRM 活動共用（抽寶箱等同列）；**icon 與選單本體規則見抽寶箱 CRM 浮動 icon 規格** | DEV §08 |
| 玩家端 · 背包 | 玩家 | 查看持卡明細與累積獎金、選攜帶遊戲、進入遊戲 | DEV §07 |
| 玩家端 · 遊戲內與結算 | 玩家 | 進場提示、FS 模式進行中的畫面規則（押注鎖定／餘額不動）、結算彈窗 | DEV §08 |
| 玩家端 · **遊戲歷程呈現** V1.12 新增 | 玩家 客服 | 查「這張卡玩了哪些局、贏多少分、最後實拿多少」：**CRM 選單 › History**（CRM 端）→ 活動分類 → **以 reference_id 分組的卡片清單** → 該卡全部局 → 單局盤面。**四層畫面屬遊戲端** | DEV §09 |
| （外部）抽寶箱活動獎項設定 | 營運 | 從獎池下拉引用發放卡（reward_id） | 見抽寶箱開發版規格 |

> **頁面之間怎麼接**：後台建卡（§06）→ 啟用後進入型錄（§05）→ 抽寶箱活動引用 → 玩家抽中發卡 → **遊戲內浮動 icon → CRM 選單 →「背包」（§08）** → 背包持有與進入遊戲（§07）→ 遊戲內使用與結算畫面（§08）→ 整卡結算（金額規則見 §02 結算三步驟、§03 全域規則）。
