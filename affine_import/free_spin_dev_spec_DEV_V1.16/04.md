# 🖥 04 · 玩家端遊戲歷程

> 依據：規格 DEV V1.16（源自 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、這個模組在管什麼

讓玩家與客服查得到「這張卡玩了哪些局、贏多少分、最後實拿多少」。

## 二、子頁目錄

| 代碼 | 頁面 | 一句話 |
|---|---|---|
| 04-A | 職責切分與入口規則 | 這一章橫跨兩個系統：CRM 端只加一個 History 入口，其餘四項都是遊戲端要改的，別開成同一張單。 |
| 04-B | L2 · 活動分類頁 | 活動分類頁多一張「FREE SPIN 卡」入口卡，與抽寶箱並列，純入口、不放統計數字。 |
| 04-C | L3 · FREE SPIN 卡片清單 | 一張卡一列，以 reference_id 為主鍵、發卡時間倒序，點列展開該卡全部局。 |
| 04-D | L4 · 該卡的局歷程（展開區） | 展開區列出這張卡的每一局（跨遊戲時間倒序混排），最下方是把「分數」接回「真金」的結算收尾列。 |
| 04-E | L5 · 單局獲獎盤面 | 盤面完全沿用既有元件，只動頂部三個數字：Balance 換成卡序號、Bet 帶幣值、Win 不帶幣值。 |
| 04-T | 本模組驗收與錯誤處理 | 歷程驗收的核心只有一句：同一張卡不管玩過幾款遊戲，都只有一列，且分數與實付金額對得起來。 |
| 04-W | Walkthrough 畫布 · 五層動線 | L1 遊戲歷程總覽 → L2 活動分類 → L3 卡片清單 → L4 局歷程 → L5 單局盤面，五層走完就是完整查詢動線。 |
