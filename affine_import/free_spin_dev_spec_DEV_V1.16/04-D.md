## 一、一句話

展開區列出這張卡的每一局（跨遊戲時間倒序混排），最下方是把「分數」接回「真金」的結算收尾列。

## 二、規則一覽

| 規則 | 說明 |
|---|---|
| 欄位 | 維持既有四欄：Time｜ID｜Profit｜Special |
| Time 欄 | 改雙行：上行時間 MM/DD HH:MM:SS，下行遊戲名（小一號灰字）；只用過一款遊戲時不顯示下行 |
| Profit 欄 | 該局贏分，純數字不帶幣值；中獎橘黃、未中獎 0 灰字。不顯示負數、不顯示 bet |
| 不顯示什麼 | 沒有單日統計列（Single Day Bet Amount／Net Win Loss） |
| 結算收尾列 | 固定置於最下方，底色略亮＋上緣分隔線；金額＝min(score, max_conversion)，帶幣值橘黃 |

## 三、條列規則

- 不放單日統計的理由：FS 局不扣真金、贏分不入 Balance，顯示這兩個數字會讓玩家誤以為自己輸了錢。
- 頁首固定說明列（不可關閉）：「此頁數字為卡片面額與累積分數，非帳戶餘額；實際入帳金額請見結算列。」
- 結算收尾列可點 → 跳到一般注單那筆「下注 0／派彩 final」；遊戲端不支援跨分類跳轉時降級為不可點但顯示注單 ID＋複製 icon。
- 卡片尚未結算：不顯示本列，不要顯示 0 或預估值。
- score 超過封頂：本列金額顯示實付上限值，其下小字註明「累積 {score}，上限 {max_conversion}，超出不計」——這是「少給錢」客訴的第一現場。
- 提前結算與到期／局數用完結算走同一列，不另做樣式。
- 遊戲已下架：遊戲名照常顯示（取快照留存值），數字部分仍須正確。

## 四、詳細說明（DEV V1.15 原文，一字未改）

### L4 · 該卡的局歷程（展開區）

#### Ⓓ · 局歷程列表

沿用既有注單列表元件，維持四欄。

**限制與規則**

- **不顯示單日統計列**（無 Single Day Bet Amount／Single Day Net Win Loss）——FS 局不扣真金、贏分不入 Balance，顯示這兩個數字會讓玩家**誤以為自己輸了錢**

- 欄位**維持既有四欄**（reference_id 已上移至分組標頭，不必再佔一欄）： **Time**｜**ID**｜**Profit**｜**Special**

- **Time 欄改雙行**：上行＝時間 MM/DD HH:MM:SS；下行＝**遊戲名**（小一號灰字）。**若該卡只用過一款遊戲，下行不顯示**

- **Profit 欄＝該局贏分，純數字不帶幣值符號**；中獎為橘黃、未中獎顯示 0 灰字。**不顯示負數、不顯示 bet**（FS 局沒有扣款這件事）

- Special 欄沿用既有（Free Game 觸發等標記）

- 列右側保留 chevron，點擊 → L5 盤面

- 排序＝**時間倒序**，跨遊戲混排

- **頁首固定說明列**（不可關閉）：「此頁數字為卡片面額與累積分數，非帳戶餘額；實際入帳金額請見結算列。」

**防呆與錯誤**

- 遊戲已下架：遊戲名照常顯示（取快照留存值），點進 L5 若盤面資產已移除則顯示降級提示，**數字部分仍須正確**

- 單張卡局數上限有限（依卡片次數），**不需分頁**；若日後開放大次數卡再議

- 卡片未使用過：顯示「此卡未使用過」，仍顯示結算列（結算金額 0 或未結算）

#### Ⓔ · 結算收尾列

把「分數」接回「真金」的那一列。

**限制與規則**

- **固定置於該卡展開區的最下方**（時間倒序之外的獨立列，樣式與局列有明顯區隔：底色略亮＋上緣分隔線）

- 內容：**時間**＝結算時間｜**標籤**「結算 · 已入主錢包」｜**金額**＝min(score, max_conversion)，**帶幣值符號、橘黃色**

- **可點** → 跳至一般注單中對應的那一筆「下注 0／派彩 final」注單（跨分類跳轉，見 §12 待確認⑩）

- 卡片尚未結算：**不顯示本列**（不要顯示 0 或預估值）

- 提前結算（§07 Ⓓ′）與到期／局數用完結算**走同一列**，不另做樣式

**防呆與錯誤**

- score 超過封頂：本列金額顯示**實付的上限值**，並在其下以小字註明「累積 {score}，上限 {max_conversion}，超出不計」——這是「少給錢」客訴的第一現場

- 跨分類跳轉若遊戲端不支援：**降級為不可點**，並在列上顯示注單 ID 短碼＋複製 icon，讓客服可自行查
