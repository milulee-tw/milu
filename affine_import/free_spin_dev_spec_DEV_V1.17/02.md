# 🖥 02 · 玩家端背包

> 依據：規格 DEV V1.20（依文件矛盾審查報告修正結算觸發、逐局注單、到期結算時點與歷程顯示；上限欄位統一為 max_bonus；其餘產品規則沿用 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、這個模組在管什麼

玩家看到手上有哪些 FREE SPIN 卡、卡片細節，選一款遊戲進場，或在封頂後提前結算。

## 二、子頁目錄

| 代碼 | 頁面 | 一句話 |
|---|---|---|
| 02-A | 背包入口（CRM 選單） | 玩家從遊戲畫面左下角的入口按鈕打開 GAME CENTER 選單，再點 BACKPACK 才真正打開背包。 |
| 02-B | 背包面板與卡片欄位 | 玩家在背包看到每張卡的全部細節（押注／次數／上限／累積獎金／剩餘時間），選一款遊戲後進場。 |
| 02-C | 選卡與進入遊戲（橫式版面） | 橫式下同一張卡的按鈕會在 VIEW DETAILS 與 CLOSE 之間切換，Select Game 改開在列表旁的獨立面板。 |
| 02-D | 提前結算與獎金上限（MAX / SETTLE NOW） | 累積獎金達上限後，卡片多出 MAX 徽章與 SETTLE NOW，讓玩家放棄剩餘局數直接把封頂獎金拿走。 |
| 02-E | 空狀態 · 待啟動 · 已過期 | 三種「不能用」的畫面：一張卡都沒有、時間還沒到、時間已經過了。 |
| 02-T | 本模組驗收與錯誤處理 | 背包最容易出事的是「多卡歧義」與「AWC 衝突」，這兩條沒過就不能上線。 |

## 三、操作流程

- 背包選卡與進場 → 見 02-C 選卡與進入遊戲（橫式版面）
- 封頂後提前結算 → 見 02-D 提前結算與獎金上限（MAX / SETTLE NOW）
