## L5 · 單局獲獎盤面

### Ⓕ · 盤面頁欄位置換

*沿用既有元件，只動頂部三個數字。*

**限制與規則**

- **盤面本體（轉軸、符號、倍率、Free Game 標記）完全沿用既有遊戲歷程元件，不做任何客製**
- **Balance 區塊整組置換**：既有的「前值 ／ ▼ ／ 後值」三行 → 改為**單行 `reference_id`**（標籤「卡序號 / Reference ID」，完整值＋複製 icon）。**不顯示任何 Balance 前後差異**——FS 局本來就不動 Balance，顯示了必然對不上
- **Bet**＝該卡的每轉押注面額（來自發卡快照 `bet`），**帶幣值符號**，其下加小字「卡片面額 · 未實際扣款」
- **Win**＝該局贏分，**純數字不帶幣值符號**（與 L4 Profit 欄同口徑）
- 頂部日期時間列（`YYYY/MM/DD HH:MM (GMT +08:00)`）沿用既有
- 「Normal Spin／Free Spin」等既有標記沿用

> [!WARNING]
> **防呆與錯誤**
> Bet 帶幣值、Win 不帶幣值是**刻意的不對稱**：面額是卡片定義的固定值（可對照背包），贏分在結算前不是錢。**開發請勿「順手統一」**
> 盤面資料已逾保存期限：顯示「此局盤面已逾保存期限」，但**時間／Bet／Win／reference_id 四項仍須顯示**（保存期限見 [09-G／09-E 開發前置與待確認](http://10.10.66.10:3010/workspace/9203b8ba-5261-4784-910b-6e0fa4a08a0b/CqGvwKWUhg) 待確認⑧）
