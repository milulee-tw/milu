### Ⓓ · 提前結算按鈕 SETTLE NOW

⟦IMG:fs_bag_01_backpack_rD.png⟧

*已封頂之後，讓玩家立刻把獎金拿走的出口。〔DEV V1.6 新增〕*

背景：`score` 達 `max_bonus` 封頂後，**再玩下去也不會再增加獎金**；提前結算就是給玩家「不用把剩下的局數玩完」的選擇。

**限制與規則**

- **顯示條件（三個同時成立才顯示）**：① `score ≥ max_bonus`（已達上限封頂）② 卡片仍有**剩餘次數** ③ 卡片**未過期**。**未封頂一律不顯示**（不是灰化，是整個按鈕不存在）
- **行為**：點擊 → 跳**二次確認彈窗**「已達最大獎金上限。提前結算將放棄剩餘 {n} 次免費旋轉，獎金 {amount} 立即入帳。」
- **確認** → 觸發結算：金額＝`max_bonus`，走 00-B 端到端流程 結算三步驟（bet=0 的結算注單入**一般注單與 Balance**）
- 結算後**先顯示 COMPLETED 完成畫面**（見下方截圖），玩家按 **CONFIRM** 才關窗，此時**卡片轉入「已過期」分頁**，顯示結算獎金與最終已用次數——**與到期結算走同一條路徑，不新增任何狀態**
- **取消** → 關閉彈窗，一切不變（不扣次、不結算、卡片留在原分頁）
- 按鈕下方須有一行**後果提示**：「放棄剩餘旋轉，立即領取封頂獎金」（Forfeit remaining spins, claim the capped bonus now）——代價要在點下去之前就講清楚，不能只靠二次確認彈窗〔V1.14 補〕
- 結算金額旁註明**入帳性質**：「入主錢包 · 真金、無流水」，與 00-B 端到端流程 結算三步驟 一致〔V1.14 補〕

> [!WARNING]
> **防呆與錯誤**
> **二次確認未按下前不觸發任何結算**；彈窗必須明示放棄的局數 {n} 與入帳金額 {amount}
> **確認的瞬間卡片剛好到期** → 以**先觸發者**結算；**整張卡只結算一次、金額相同、不重複入帳**
> 結算完成前按鈕須進入處理中狀態，避免連點造成重複請求
> 剩餘次數已為 0（局數用完）時不顯示本按鈕——那條路徑由自動結算接手

⟦IMG:fs_bag_04_settle_confirm.png⟧

*提前結算二次確認 · Ⓐ 彈窗（明示放棄局數 {n} 與入帳金額 {amount}）· Ⓑ **CONFIRM 在左、CANCEL 在右**——刻意與其他畫面相反，防手滑誤觸 · 點圖放大*

彈窗文案：「Settle now? — You've reached the max win cap. Settling now forfeits the remaining {n} free spins; {amount} will be credited immediately.」與 14 語系表一致。小字說明另列已贏金額與上限的差異。

⟦IMG:fs_bag_05_settle_completed.png⟧

*CONFIRM 後顯示的完成畫面 · Ⓐ COMPLETED 標題 · Ⓑ Card No.（不顯示 CampaignID／遊戲圖示——結算是在背包直接觸發，不是由某一場遊戲的進場流程走出來的）· Ⓒ Bonus Amount（等同 Max 上限）＋Max Cap Reached 徽章 · Ⓓ **CONFIRM**，本畫面唯一出口 · 點圖放大*

CONFIRM 後**先顯示本完成畫面**，玩家按 **CONFIRM** 才關窗回到背包列表；畫面與 05 美術 結算彈窗 為同一元件的簡化版。

**限制與規則**

- **遊戲牆最多 8 款**（上限見 01-B 建卡與編輯表單）

- **AWC FREE SPIN 衝突檢查**〔DEV V1.6 新增〕：選擇指定遊戲時，**先查詢玩家在該遊戲是否存在未使用完的 AWC FREE SPIN**

### Ⓕ · CLOSE／PROCEED

⟦IMG:fs_bag_01_backpack_rF.png⟧

*CLOSE 收合卡片；PROCEED 觸發「綁卡 → 取一次性入口 → 進入遊戲」。*

**限制與規則**

- **未選遊戲時 PROCEED 押灰不可按**；選定一款後才亮起
- 押灰態**不可做成隱藏**——按鈕要看得到但按不動，玩家才知道「還差一步」，而不是以為卡片壞了〔V1.14 補〕
- 押灰時按鈕下方顯示提示「**請先選擇一款遊戲**」（Select a game to start）〔V1.14 補〕
- 按下 PROCEED 後，系統**先綁定這張卡的卡序號**再取一次性入口——這一步解決「同一款遊戲持多張卡」的歧義，也讓「續玩同一張卡」扣到正確的局數池
- 未用完的卡（如 4/10）續玩時帶**同一張卡**，續扣同一個池、**不開新卡**
- 文案見 14 語系表

> [!WARNING]
> **防呆與錯誤**
> 連點做節流：同卡短時間內只取一次連結
> 一次性連結只能用一次；失效重取的處理見本章〈本頁錯誤處理〉
> 進入遊戲之後（進場提示、遊戲中畫面、結算彈窗）見 03 遊戲內與結算

## 背包顯示欄位

背包資料**以我方快照為主**；集成商的查詢結果只作對帳校驗。玩家點開背包即可看到每張卡的全部細節。

| 背包顯示 | 欄位 / 來源 |
|---|---|
| 多少押注額 | bet（每轉押注 · 來自道具基礎值） |
| 剩餘 / 總次數 | rounds_left / num_of_rounds |
| 最大獎金金額 | max_bonus |
| 可玩哪些遊戲 | game_ids[]（圖示牆） |
| 剩餘可使用時間 | valid_to − now（倒數；少於 24 小時轉紅提示）<br>**待啟動卡改顯示 valid_from − now 開始倒數** |
| 狀態 | 待啟動 / 全新未使用 / 使用中 / 即將到期 / 已過期 |
| 目前累積獎金 | 暫存分數 score（每局贏分累加，未入 Balance）；達 max_bonus 顯示「已達上限封頂」 |
| 最終入帳 | 主錢包真金（無流水） |
