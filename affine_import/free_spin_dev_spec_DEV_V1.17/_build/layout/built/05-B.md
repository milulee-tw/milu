## 標籤 — 狀態徽章（五態）

五個狀態各自對應一組顏色與樣式規則，不只靠色相區分 — 明度與底紋也同步變化，色弱玩家仍能辨識。

⟦IMG:fs_art_10_tag_states_badges.png⟧

*待啟動、使用中、全新、即將到期、已過期 — 五態徽章。*

⟦IMG:fs_art_11_tag_states_popups.png⟧

*編號 1「即將到期」與編號 2「待啟動」— 收合與展開後的外觀與一般卡片相同（VIEW DETAILS 可展開瀏覽 Select Game），但**不可選取遊戲、PROCEED 永遠押灰**（見 02-E），分頁歸屬也不同〔V1.20 改〕。編號 3「已過期」— 無 VIEW DETAILS 按鈕、不可展開，也沒有其他互動；整張卡片透明度降低約 50％，呈現置灰效果。*

「待啟動」與「即將到期」等其他狀態一樣可以展開瀏覽 Select Game（僅顯示於背包「PENDING」篩選，尚未到開始時間不影響瀏覽）；「已過期」則整卡不可互動、無法展開（僅顯示於背包「EXPIRED」篩選）。

| 狀態 | 顏色 | 樣式規則 |
|---|---|---|
| 待啟動 | 藍紫 | 僅顯示於背包「PENDING」篩選；玩家可展開查看此卡可用的遊戲，但尚無法實際使用兌換 |
| 使用中 | 金 | 玩家使用過此卡後，即轉為此狀態 |
| 全新 | 綠 | 尚未使用（已用 0 次）且已可使用 |
| 即將到期 | 紅 | 剩餘時間少於 24 小時；顯示倒數計時 |
| 已過期 | 灰 | 無 VIEW DETAILS 按鈕、不可展開，整張卡片透明度降低約 50％呈現置灰效果；僅顯示於背包「EXPIRED」篩選 |

⟦IMG:fs_art_12_tag_states_lifecycle.png⟧

***卡片生命週期** — 一張FREE SPIN卡有**四條**結束路徑：**①** 把旋轉全部用完，結算 `min(score, 上限)`；**②a** 到期且從未使用，**不結算**（不寫結算注單）；**②b** 到期但已使用一部分，**結算 `min(score, 上限)`**（剩餘未轉次數視同放棄）〔V1.20 改〕；**③** 獎金達上限後選擇 SETTLE NOW 提早結算。達到上限本身不會自動結束卡片，玩家仍可繼續用完剩餘旋轉。四條路徑最終都進入同一個分頁——其中 ①②b③ 都是**已結算**、只有 ②a 是真正的未使用過期。*

## Select Game 遊戲格 — 方塊狀態

三種樣式互斥 — 一個方塊在同一時間只會是其中一種；選取狀態同時以邊框、打勾徽章與文字粗細三個線索標示，不單靠顏色。

⟦IMG:fs_art_13_tile_states.png⟧

*由左至右：Selected、Default、Locked。*

| 狀態 | 樣式規則 |
|---|---|
| Selected | 深色粗邊框＋右上角打勾徽章，遊戲名稱文字加粗；同一時間僅能有一格為此狀態 |
| Default | 灰底方塊、一般樣式，可點擊選取 |
| Locked | 深灰底方塊，縮圖上覆蓋鎖頭圖示，遊戲名稱文字變暗，不可點擊；點擊時顯示提示「**請先完成此遊戲的免費旋轉**」（觸發條件與文案見 02 玩家端背包 Ⓔ；玩家端一律不出現「AWC」字樣） |
