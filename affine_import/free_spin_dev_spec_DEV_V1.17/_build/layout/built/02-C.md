## FREE SPIN卡 — 橫式選取前後對照

橫式下，同一張FREE SPIN卡在未選取與已選取時，卡片下方的按鈕會換成不同文字：未選取為 VIEW DETAILS，選取後同一位置變成 CLOSE，並在列表旁開啟獨立的 Select Game 面板；面板內僅有 PROCEED，CLOSE 留在卡片上，不會在面板中重複出現。另外，FREE SPIN卡置入橫式版面時，尺寸會略微縮小，並非直式卡片原尺寸的直接搬移。

## 區域詳細說明 · 橫式選取

### 1 卡片按鈕（VIEW DETAILS ／ CLOSE）

*同一個位置，兩種文字。*

**限制與規則**

- 未選取時顯示 **VIEW DETAILS**；點擊選取後，同一個按鈕位置變成 **CLOSE**，用來取消選取、收回 Select Game 面板
- 選取狀態**同時以卡片外框標示**

> [!WARNING]
> **防呆與錯誤**
> —

### 2 Select Game 面板

*選取後才開啟的獨立面板。*

**限制與規則**

- 選取任一張FREE SPIN卡後才會在列表旁開啟；面板內**僅有 PROCEED**（取消／收回改由卡片上的 CLOSE 負責）

> [!WARNING]
> **防呆與錯誤**
> 面板內容細節見「遊戲格狀態」小節
