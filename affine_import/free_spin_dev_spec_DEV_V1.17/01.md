# 🖥 01 · 後台發放卡管理

> 依據：規格 DEV V1.20（依文件矛盾審查報告修正結算觸發、逐局注單、到期結算時點與歷程顯示；上限欄位統一為 max_bonus；其餘產品規則沿用 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、這個模組在管什麼

營運維護發放卡型錄、建卡與編輯，以及各幣別的道具基礎值。

## 二、子頁目錄

| 代碼 | 頁面 | 一句話 |
|---|---|---|
| 01-A | 發放卡列表 | 營運在這頁看所有發放卡、展開查哪些活動在用它，並進到建卡或編輯。 |
| 01-B | 建卡與編輯表單 | 營運在這頁建一張卡：選星級、勾遊戲、填次數與封頂、設有效期，按「建立發放卡」並二次確認即生效。 |
| 01-C | 道具基礎值與公版數值 | 每個幣值一組 1★–5★，營運填「每轉押注」，次數與封頂倍數也可逐段調整（預設 10 次、×10）；face_value 與 max_bonus 自動算。 |
| 01-D | 後台防呆與友善度 | 後台這兩頁的防呆只有一個目的：別讓一張設定不完整或還在用的卡流到玩家手上。 |
| 01-T | 本模組驗收與錯誤處理 | 後台兩頁一起驗：刪除保護、未結束口徑、ID 產生時點、自動計算、快照凍結，五件事測過就算通過。 |
