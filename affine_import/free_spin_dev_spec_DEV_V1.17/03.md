# 🖥 03 · 遊戲內與結算

> 依據：規格 DEV V1.20（依文件矛盾審查報告修正結算觸發、逐局注單、到期結算時點與歷程顯示；上限欄位統一為 max_bonus；其餘產品規則沿用 DEV V1.15）／ 後台原型 2026-08-25 實拍 ／ 背包原型 2026-09-14 新版線框

## 一、這個模組在管什麼

玩家進到遊戲之後看到什麼、哪些數字會動、哪些一定不能動，以及整卡結束時的結算畫面。

## 二、子頁目錄

| 代碼 | 頁面 | 一句話 |
|---|---|---|
| 03-A | 進場提示彈窗 | 進場先跳一次彈窗，告訴玩家「有幾局可玩」與「最多能拿多少」，玩家點任意處才開第一局。 |
| 03-B | 遊戲中（FS 模式） | FS 模式下畫面有三處變化：常駐 FREE SPINS 標示、BET 鎖成卡片面額、旋轉鈕改成 FREE {n} 剩餘局數計數器。 |
| 03-C | CRM 入口與活動頁浮層（iframe） | 背包是在遊戲內以 iframe 浮層開啟的，玩家不必離開遊戲；本頁定義入口路徑與「什麼時候必須讓開」。 |
| 03-D | 結算彈窗 | 卡片結束時跳一次結算彈窗，顯示這張卡最後給了多少錢，按 CONFIRM 回一般模式。 |
| 03-E | FS 卡局數 vs. 遊戲自身免費遊戲 | 遊戲自己觸發的免費遊戲不扣卡片局數，但那段的贏分照樣累加到 score。 |
| 03-T | 本模組驗收與錯誤處理 | 遊戲內最高優先的缺陷只有一個：進場後沒進入 FS 模式卻讓玩家用真錢開局。 |

## 三、操作流程

- 進場到整卡結算 → 見 03-A 進場提示彈窗

- 見 09-E 待確認事項（共用一套流水號）
