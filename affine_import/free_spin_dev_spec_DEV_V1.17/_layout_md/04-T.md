## 本頁驗收

| # | 情境 | 預期結果 |
|---|---|---|
| H-01 | CRM 選單點 History | 選單**收合**；開啟遊戲歷程頁並**落在「活動」分類（L2）**，看得到抽寶箱與 FREE SPIN 卡兩張入口卡；**不直跳卡片清單** |
| H-01b | 檢查選單與背包 | History 位於**選單最下方**、主標 History／副標 RECORDS；**背包浮層內找不到任何歷程入口**（單一入口） |
| H-01c | FS 卡尚未上線時 | History 項目**掛 SOON 佔位、不可點**，樣式同 Mission／Ranking |
| H-02 | 未持任何 FS 卡的玩家點 History（上線後） | History 項目**仍顯示且可點**（不隱藏、不置灰）；L2 的 FREE SPIN 卡入口卡**仍顯示**；點進 L3 顯示空狀態文案而非空白畫面 |
| H-03 | L2 兩張入口卡 | 兩張卡**皆無** TOTAL BETS／Net Win/Lose 統計列 |
| H-04 | 同一張卡跨兩款遊戲各玩數局 | L3 只出現**一列**（一張卡）；展開後兩款遊戲的局**時間倒序混排**，Time 欄第二行分別標出遊戲名 |
| H-05 | 檢查 L4 是否有單日統計 | **不存在** Single Day Bet Amount／Single Day Net Win Loss 兩個數字 |
| H-06 | 已結算的卡 | L3 該列結算欄顯示**帶幣值**的實付金額；展開後最下方有結算收尾列，金額一致 |
| H-07 | 使用中（未結算）的卡 | L3 結算欄顯示「進行中」；展開後**沒有**結算收尾列；**畫面上不出現任何預估金額** |
| H-08 | score 超過 max_bonus 的卡 | L3 累積分數顯示**實際 score**＋「已封頂」提示；結算列金額＝`max_bonus`，並註明「累積 {score}，上限 {max_bonus}，超出不計」 |
| H-09 | 點結算收尾列 | 跳至一般注單該筆「下注 0／派彩 final」；若遊戲端不支援跨分類跳轉，則**降級為不可點但顯示注單 ID＋複製 icon** |
| H-10 | 點單局進 L5 | 頂部**只有** `reference_id` 單行，**沒有 Balance 前後值**；Bet 帶幣值＋「卡片面額 · 未實際扣款」小字；Win **不帶幣值** |
| H-11 | L5 按 ← | 回到**該卡仍為展開狀態**的 L4 |
| H-12 | 日期篩選器選一個有使用紀錄的日期 | L3 只列出該日有使用紀錄的卡；**展開後仍顯示該卡全部局**（不被日期裁切） |
| H-13 | 日期篩選器選一個沒有紀錄的日期 | 顯示「該日期無使用紀錄」＋「清除篩選」，非空白畫面 |
| H-14 | 複製 `reference_id` | 取得的是**完整值**（非畫面上的短碼），與背包卡片明細的卡號一致 |
| H-15 | 與一般注單交叉比對 | FS 的每一局**不出現在一般注單**；一般注單只有結算那一筆，金額與結算收尾列一致 |
