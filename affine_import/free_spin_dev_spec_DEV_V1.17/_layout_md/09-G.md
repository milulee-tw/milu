## 遊戲端回傳的錯誤訊息〔V1.18 新增〕

> [!NOTE]
> ℹ️ **這是本文件唯一列出錯誤訊息的地方。**原則上本書不指定錯誤代碼（見 [00-A 功能目的與範圍](http://10.10.66.10:3010/workspace/9203b8ba-5261-4784-910b-6e0fa4a08a0b/d4-a-OC2Ms) 文件定位），但下列訊息**玩家端必須各自對應處理**——顯示什麼文案、能不能重試、要不要擋下開局——所以在此列出。**訊息字串本身以遊戲端實作為準**，本表只界定「什麼情況會收到它」。

| Message | 觸發時機 |
|---|---|
| `free voucher not found` | 玩家送的 ref 不在 server cache（卡剛過期被 cron 清、非法 ref、client 快取失效） |
| `game not supported by this voucher` | 卡的 `game_code` 不含當前遊戲 |
| `invalid spin parameter for voucher` | 幣別／BuyType／BetAmount 不符卡的規範 |
| `voucher rounds used up` | `spin_count >= round`，玩家轉完但沒按領獎又送 spin |
| `free voucher expired` | 卡已過 `end_time` |
| （空 message · Before StartTime） | 卡還沒生效（`start_time > now`） |
| `AWC free spin available for this game, please use it first` | 同遊戲有 AWC 卡未用完，禁止使用 CRM 卡 |
| `free voucher not owned by member` | 玩家 A 拿 B 的 ref（多見於 hack／bug） |
| `free voucher settle failed` | 結算失敗（非 PENDING，是真失敗） |

> [!WARNING]
> ⚠️ **玩家端不得直接顯示這些英文原文。**`AWC free spin available for this game, please use it first` 對應的玩家端文案，依 DEV V1.7 定案為「**請先完成此遊戲的免費旋轉**」——**玩家端一律不出現「AWC」字樣**（見 09-I 多國語系總表）。每一條實際要顯示的文字見下方〈**玩家端錯誤文案**〉；其餘語系翻譯見 [09-E 待確認 ⑬](http://10.10.66.10:3010/workspace/9203b8ba-5261-4784-910b-6e0fa4a08a0b/YRXip9cvxh)。

## 非錯誤、但需要辨識的回應狀態〔V1.18 新增〕

下列三種情境的 `code` 都是 **0**（不是錯誤），玩家端要再看 `settle_status` 與 `payout` 才知道實際發生什麼，不可一律當成功處理。

| 情境 | Response |
|---|---|
| 領獎失敗但已 PENDING | `code = 0` ＋ `voucher.settle_status = 4` → SETTLE NOW 反灰、禁止重複點擊，交由 Retry 機制處理（見 [09-A 結算狀態與失敗重試](http://10.10.66.10:3010/workspace/9203b8ba-5261-4784-910b-6e0fa4a08a0b/urGMQ8nPyl)） |
| 領獎成功 | `code = 0` ＋ `voucher.settle_status = 2` ＋ `payout > 0` |
| 領獎但無派彩金額 | `code = 0` ＋ `payout = 0` → **仍須跳結算彈窗顯示 0**，不可靜默結束（見 03-T 驗收 ⑤） |

## 玩家端錯誤文案〔V1.19 新增〕

原則：**每一句都要告訴玩家「接下來可以做什麼」**（重新整理、回背包換遊戲、等倒數、稍後再試、聯繫客服），不能只說「失敗了」；**不出現技術詞**（ref、cache、AWC、settle 等）。左欄是遊戲端回傳的訊息，前端依此對應顯示右側文案。

| 遊戲端訊息／狀態 | 玩家端文案（繁體中文） | English |
|---|---|---|
| `free voucher not found` | 找不到這張 FREE SPIN 卡，可能已過期。請回到背包重新整理後再試。 | We couldn't find this FREE SPIN card — it may have expired. Please refresh your Backpack and try again. |
| `game not supported by this voucher` | 這張 FREE SPIN 卡不能在這款遊戲使用。請回到背包，從卡片的遊戲清單中選一款。 | This FREE SPIN card can't be used in this game. Go back to your Backpack and choose a game from the card's list. |
| `invalid spin parameter for voucher` | 免費旋轉暫時無法開始。請離開遊戲，再從背包重新進入；若仍無法開始，請聯繫客服。 | Free Spins couldn't start. Please leave the game and re-enter from your Backpack. If it still fails, contact Customer Service. |
| `voucher rounds used up` | 這張卡的免費旋轉已全部用完，獎金會自動入帳。請到背包查看結算結果。 | You've used all Free Spins on this card. Your winnings will be credited automatically — check your Backpack for the result. |
| `free voucher expired` | 這張 FREE SPIN 卡已過期，已累積的獎金會自動入帳。請到背包的「已過期」查看。 | This FREE SPIN card has expired. Any winnings will be credited automatically — see Expired in your Backpack. |
| （空 message · Before StartTime） | 這張 FREE SPIN 卡還沒開始，請等倒數結束後再使用。 | This FREE SPIN card isn't active yet. Please try again when the countdown ends. |

> ℹ️ 「領獎但無派彩金額」（`code = 0` ＋ `payout = 0`）**不另外顯示訊息**——照常跳結算彈窗顯示 0 即可（見 [03-T 驗收 ⑤](http://10.10.66.10:3010/workspace/9203b8ba-5261-4784-910b-6e0fa4a08a0b/eCEYcmAy9G)）。
