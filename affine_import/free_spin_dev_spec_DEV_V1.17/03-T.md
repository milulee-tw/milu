## 本頁驗收情境

| 情境名稱 | 前提（測試前先準備好什麼） | 動作（做什麼） | 預期結果（應該看到什麼） |
|---|---|---|---|
| **① 進場提示只跳一次** | 持一張剩餘 5/10 的卡，已選攜帶遊戲 | 進入遊戲，關掉彈窗後玩 2 局，再開背包重進同一張卡 | ① 第一次進場跳彈窗，顯示 **5 SPINS**（不是 10）；② 玩到一半不再跳；③ 重進時顯示剩餘 3 SPINS，仍只跳一次 |
| **② 錢包全程不動** | 記下進場前的錢包餘額 | 玩完全部免費局（其中至少 1 局有贏分） | ① FS 期間**每一局結束餘額都不變**；② 結算彈窗出現時餘額**顯示仍不變**（後端已先入帳），**按 CONFIRM 關閉彈窗後**餘額顯示才增加 Bonus Amount〔V1.20 改〕 |
| **③ 局數用完自動結算** | 持一張剩 1 局的卡 | 玩完最後一局 | ① 計數器歸 0 且**無法再開局**；② 自動跳結算彈窗；③ 金額＝min(score, 封頂) |
| **④ 贏分超過封頂** | 卡片封頂 ₱300，玩到 score 超過 ₱300 | 玩完剩餘局數 | ① 結算彈窗顯示 **₱300**（不是實際贏分）；② 背包已過期卡顯示同一數字 |
| **⑤ 結算金額為 0** | 全部免費局都沒中獎 | 玩完最後一局 | ① **仍跳結算彈窗**、金額顯示 0；② 不可靜默結束讓玩家以為卡片消失 |
| **⑥ 到期時人不在遊戲** | 卡片還剩局數但即將到期，玩家已離開遊戲 | 等到卡片到期後，玩家再打開背包 | ① 不補跳遊戲內彈窗；② 背包「已過期」分頁該卡顯示**結算獎金**；③ 錢包已入帳 |
| **⑦ 遊戲自身免費遊戲不扣局數** | 選一款會觸發 Scatter 免費遊戲的卡內遊戲 | 在 FS 卡局數中觸發遊戲自身的免費遊戲並玩完 | ① 那段期間**卡片局數不減少**；② 該段贏分**有算進**最終結算金額 |
| **⑧ 押注鎖定** | 卡片面額 bet＝2000 | 在 FS 模式嘗試調整押注 | ① 押注顯示 2000 且**無法調整**；② 回一般模式後押注恢復可調 |
| **⑨ spin 自動關浮層**<br>〔V1.8 改〕 | FS 模式中、**CRM 選單或背包浮層開著** | 按下 SPIN | ① **選單與背包浮層立即關閉**；② **吸附浮動 icon 保留**在畫面上（不一起消失）；③ 該局**照常進行並扣次**（局數與 `score` 計算不受影響） |
| **⑩ 轉動中浮層鎖定**<br>〔V1.20 改〕 | FS 模式中、**CRM 活動頁浮層開著** | 按下 SPIN，轉動中點浮層原本的位置 | ① 浮層**隨 SPIN 立即關閉**；② 轉動中點擊該位置**沒有任何反應**（不會誤觸浮層按鈕）；③ **動畫結束後**點 icon 可再開啟活動頁 |
| **⑪ 轉動中點 icon**<br>〔V1.8 新增〕 | FS 模式**轉動中**（開獎動畫未結束） | 點吸附浮動 icon | ① icon **半透明**；② **選單不展開**、**無任何反應**；③ **轉完後恢復可展開**，點 icon 正常跳出 CRM 選單 |
| **⑫ 選單進背包**<br>〔V1.8 新增〕 | 遊戲畫面、**吸附浮動 icon 可見**（非轉動中） | 點 icon → 展開選單 → 點「背包」 | ① **選單收合**；② **背包浮層開啟**，內容與規則同 [02 玩家端背包](affine://02-B)；③ 選單中**其他 CRM 活動入口（抽寶箱等）不受影響** |
| **⑬ 一般模式開背包**<br>〔V1.9 新增〕 | 玩家在**一般模式**（**未使用任何 FS 卡**） | 點 icon → 選單 → 點「背包」 | ① icon **在一般模式同樣可見可點**；② **背包浮層正常開啟**；③ **內容與版面與 [02 玩家端背包](affine://02-B) 定義完全一致**（無簡化版） |

## 本頁錯誤處理

| 狀況 | 系統怎麼反應 | 玩家（或營運）看到什麼 |
|---|---|---|
| **進場後沒進入 FS 模式**<br>（遊戲端沒收到卡） | **一律擋下、不得以玩家真錢開局**；不扣卡片局數，卡片留在背包維持原狀。 | 玩家：看不到 FS 標記與計數器時**不會誤用真錢**；提示回背包重新進入。（此為最高優先缺陷） |
| **結算前斷線 / 關 App** | 結算**由伺服器判定，不依賴畫面**；已成立的結算照常入帳。重連回到該遊戲時**補顯示一次**結算彈窗，之後不再顯示。 | 玩家：回來看到一次結算結果；就算沒看到，錢包與背包都查得到金額。 |
| **彈窗金額與背包不一致** | 以**結算注單**為唯一準；畫面差異視為顯示問題，重整後應一致。 | 營運：以 `fs_settled` 事件與該筆結算注單為準回覆客訴。 |
| **局數還沒用完就離開遊戲** | **不觸發結算**；卡片留在背包、局數與 `score` 保留。可回背包**換一款卡內遊戲**續玩，續扣同一個局數池。 | 玩家：背包卡片仍為「使用中」，剩餘次數與累積獎金與離開前一致。 |
| **玩到一半跨過到期時間** | **當下那一局照常結束**，之後不再起新局，直接結算並跳彈窗。 | 玩家：手上那局玩完後即出現結算彈窗；剩餘未玩局數作廢。 |
| **結算入帳失敗** | **先不跳彈窗**，重試直到成功；連續失敗須產生告警給營運，卡片維持未結算狀態不得吃掉。 | 玩家：暫時看不到結算結果，但**卡片與累積獎金都還在**，不會憑空消失。 |
| **轉動中誤觸浮層** 〔V1.6〕 | **所有點擊被阻擋、不觸發任何背包操作**（不選卡、不選遊戲、不取遊戲入口、不觸發提前結算）。 | 玩家：**浮層半透明、無反應**；動畫結束後才恢復可操作。 |
